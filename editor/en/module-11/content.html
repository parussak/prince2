Chapter 11: Progress

Purpose and SnakeBite example

The progress practice compares actual achievement and forecast outcomes with the approved plans and tolerances. PRINCE2 7 uses seven performance targets: benefits, cost, time, quality, scope, risk and sustainability. A deviation is the difference between actual performance and the plan; a forecast predicts a future position. An exception is a forecast breach of the tolerance at the relevant management level. Escalation passes that decision to the next authority.

SnakeBite example: Tomek reports that API integration is two days late. His work package has three days of time tolerance, so he reports the deviation and manages within it. If the forecast breaches the work package tolerance, he tells Zosia. If Zosia forecasts a breach of stage tolerance, she sends an exception report to the project board. The board decides whether to request an exception plan, revise tolerances within its authority, escalate further or close the project.

Key terms, responsibilities and management products

Reports by level: checkpoint report, team manager → project manager; highlight report, project manager → project board. At a stage boundary, the end stage report supports the board’s next decision. At closure, the end project report compares the overall outcome with the baseline. The lessons report shares experience. An exception report explains a forecast tolerance breach and options. The project log contains the daily log for informal notes and other project records.

Managing by exception: the board delegates authority through stage tolerances, and the project manager delegates through work package tolerances. Each level decides within its authority and escalates forecast breaches. Review trends as well as current values; a present deviation alone is not automatically an exception.

What is tolerance?

Permissible deviation from a plan for a delegated level of management.

Who authorizes an exception plan?

The project board authorizes a replacement stage or project plan within its authority.

What is the daily log?

Part of the project log for informal issues, notes and observations.

What are the seven performance targets?

Benefits, cost, time, quality, scope, risk and sustainability.

Additional textbook-aligned explanation

Seven targets and tolerance

Progress control considers time, cost, quality, scope, benefits, risk and sustainability. A tolerance defines permitted deviation from a plan or target at a given management level. A forecast is the expected future result; a deviation is a difference from plan; an exception exists when the forecast exceeds tolerance. The project manager may take corrective action within the delegated stage tolerance. A forecast stage exception is escalated to the project board with an exception report; an expected project tolerance breach must go to the business layer.

Reports at the right level

A team manager reports work package progress to the project manager in checkpoint reports. The project manager reports stage progress to the project board in highlight reports. At a boundary an end stage report compares results with the approved stage plan. An end project report assesses overall delivery, and lessons reports preserve findings for later projects. An exception report supports a decision when forecast tolerance is exceeded. Reporting frequency and detail are tailored, while thresholds for escalation remain explicit.

Use evidence for a decision

On SnakeBite, Zosia compares completed API tests and costs with the stage baseline and forecasts the remainder. A small variance still within tolerance supports a corrective action. A forecast over the stage cost tolerance triggers an exception report and a decision by the board; a team checkpoint report alone is neither an authorization nor a replacement plan.

SnakeBite Scenario: Organizing and Roles

🎓 Hard knowledge for the Foundation exam (Organizing)
Official definitions, roles on the Project Board and a question test.
💡 Remember
The purpose of the Organizing practice is to define and establish a project accountability and responsibility structure (who).

Roles in the Project Board

project executive(Executive - Artur)

A single point of accountability for the project, determined by the business.This accountability CANNOT be delegated.He represents business and chairs the Project Board.

Senior user(Senior User - Maya)

Represents the user community. Is accountable for the approach taken to capture user requirements and benefit specifications aligned with the business case.

Main supplier(s).(Senior Supplier - Kamil)

Is responsible for the quality of products supplied by suppliersand for the technical integrity of the project.

Management and Delivery

Project manager(Project Manager - Zosia)

Responsible for ongoing project management. Has the authority to conduct the project on behalf of the Project Board, within agreed tolerances and constraints. Manages 7 areas:benefits, costs, time, risk, quality, scope, sustainability.

Team manager(Team Manager - Tomek)

Responsible for carrying out work in accordance with agreed specifications and within tolerances agreed with the Project Manager. The project manager assigns work to the team manager in the formdescription of the Work Package, in accordance with the Commercial Management Approach.

💡 Remember
Project arrangements are not just formal contracts.The Project Manager must secure ALL project arrangements: both formal contracts with external suppliers and informal arrangements with colleagues - e.g. when and how changes/arrangements are made. In SnakeBite, this applies to both the contract for the graphics engine and Zosia's arrangements with Tomek.

Other roles

Project supervision(Project Assurance)

Project Board members are accountable for the oversight of their areas. The Project Board may appoint separate people for this task, butThese can NEVER be: The Project Manager, Team Members or Project Support.Appointing persons to perform supervisory tasks does not transfer the accountability of the members of the Board.

Project support(Project Support)

Administrative services, tool guidance, planning, etc. Default is the responsibility of the Project Manager, but CAN be delegated. Project support can be established as a project office.
